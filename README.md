# Clash Jogo Teste

Jogo mobile Android inspirado em estrategia, com construcao de base, tropas e evolucao de gameplay.

## Visao geral

Este repositorio faz parte dos projetos da conta **snep-isc**. A ideia e manter o codigo organizado, documentado e facil de continuar evoluindo.

## Funcionalidades

- Projeto Android
- Estrutura Gradle
- Base para jogo mobile de estrategia

## Tecnologias

- Java
- Android
- Gradle

## Como usar

Clone o repositorio:

``bash
git clone https://github.com/snep-isc/clashjogoteste.git
cd clashjogoteste
``

Comandos ou passos principais:

- `Abra o projeto no Android Studio`
- `Sincronize o Gradle`
- `Compile e execute no emulador ou aparelho`

## Estrutura

A estrutura pode mudar conforme o projeto evolui. Consulte os arquivos e pastas do repositorio para entender a organizacao atual.
